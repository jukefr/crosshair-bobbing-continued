# ICON.md — project icon system

This file documents the shared Modrinth/desktop icon style used by jukefr's Minecraft mods.
It exists so every project looks like part of the same family, and so future icons can be
reproduced without guessing colours or geometry.

The icons are hand-authored SVG files. They are **not** generated by an image model, contain no
third-party art, and are safe to ship under the project's GPL-3.0-only license.

## Canvas and construction

- **Size:** 512 × 512 PNG, rendered from SVG.
- **Shape:** rounded square, corner radius **96 px** on the 512 canvas.
- **Background:** vertical linear gradient, dark and tinted toward the project's accent colour.
- **Border:** 2 px, white at **7% opacity**, inset 11 px, corner radius 87.
- **Glyph:** one bold, centred, instantly readable symbol in white/off-white. No text — text is
  unreadable at Modrinth's 64 px thumbnail size.
- **Accent:** one accent colour per project. Use it for strokes, secondary shapes, and the glow.
  Do not use more than two accent elements.
- **Glow:** Gaussian blur (`stdDeviation` 7–8) merged back under the source shape. Keep it soft;
  the icon must still read as a flat symbol at 64 px.
- **Padding:** keep the glyph inside roughly 48 px of the canvas edge.
- **Contrast:** the white glyph must remain clear against the dark background in greyscale.

## Files and locations

Every mod keeps the same icon in two places:

| Path | Purpose |
|---|---|
| `resources/icon.svg` | Editable source of truth. |
| `resources/icon.png` | 512 × 512 export used for Modrinth/project branding. |
| `src/main/resources/assets/<namespace>/icon.png` | Icon shown in the in-game mod list and used by `fabric.mod.json` / `neoforge.mods.toml`. |

Render and verify:

```bash
rsvg-convert -w 512 -h 512 resources/icon.svg -o resources/icon.png
identify resources/icon.png          # must report 512x512
cp resources/icon.png src/main/resources/assets/<namespace>/icon.png
```

## Uploading to Modrinth

The icon endpoint is `PATCH /v2/project/{id}/icon?ext=png` with the raw PNG as the body.
A successful upload returns **204 No Content**.

```bash
set -a; . ~/Projects/Grindset/mods/death-messages/.env; set +a
UA="jukefr/icon-maker/1.0 (code@juke.fr)"
curl -X PATCH "https://api.modrinth.com/v2/project/<project-id>/icon?ext=png" \
  -A "$UA" -H "Authorization: $MODRINTH_TOKEN" \
  -H "Content-Type: image/png" --data-binary @resources/icon.png
```

## Starter SVG template

Copy this into `resources/icon.svg` for a new project, replace `ACCENT`, `TOP`, `BOTTOM`, and
draw the glyph inside the marked group. Keep the background, border, and filter blocks unchanged
so the family stays consistent.

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="512" height="512" viewBox="0 0 512 512">
  <defs>
    <linearGradient id="bg" x1="0" y1="0" x2="0" y2="1">
      <stop offset="0" stop-color="TOP"/>
      <stop offset="1" stop-color="BOTTOM"/>
    </linearGradient>
    <filter id="glow" x="-40%" y="-40%" width="180%" height="180%">
      <feGaussianBlur stdDeviation="7" result="b"/>
      <feMerge><feMergeNode in="b"/><feMergeNode in="SourceGraphic"/></feMerge>
    </filter>
  </defs>

  <rect width="512" height="512" rx="96" fill="url(#bg)"/>
  <rect x="11" y="11" width="490" height="490" rx="87"
        fill="none" stroke="#ffffff" stroke-opacity="0.07" stroke-width="2"/>

  <!-- GLYPH: one bold white symbol, optionally with ACCENT strokes, inside 48 px padding. -->
  <g filter="url(#glow)" fill="none" stroke="#ffffff" stroke-width="22"
     stroke-linecap="round" stroke-linejoin="round">
    <!-- replace with the project glyph -->
  </g>
</svg>
```

## Checklist for a new icon

- [ ] 512 × 512 PNG exported from an SVG kept at `resources/icon.svg`.
- [ ] Rounded 96 px corners, tinted dark gradient, subtle 7% white border.
- [ ] One bold glyph, no text, readable at 64 px and in greyscale.
- [ ] Accent colour differs from the four existing projects.
- [ ] Copied to `resources/icon.png` and `src/main/resources/assets/<namespace>/icon.png`.
- [ ] Uploaded to Modrinth and the icon hash changed on the project page.
- [ ] Palette table above updated if a new accent/background pair was introduced.
